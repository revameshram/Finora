# Finora — Build Prompts (Phase by Phase, Module by Module)

> Copy one prompt at a time into your AI-IDE session. Every prompt starts with the same mandatory pre-flight — do not skip it, even if you think you remember the current state. `PROJECT.md` and `SYNC_LOG.md` are the only source of truth for "what's actually built" since the two of you aren't working simultaneously.

---

## How to use this doc

- Prompts are grouped: **Phase 0** (Alok, solo) → **Phase 1** (Track A / Reva, and Track B / Alok, in parallel-by-turns) → **Phase 2** (joint).
- Every prompt = Pre-Flight → Step 0 (written plan) → Build → Post-Flight. Do not let the AI-IDE skip Step 0 or the Post-Flight — both are load-bearing for the other person's next session.
- Reference docs a prompt may point to: `Finora_Master_Reference.docx` (UX/data-model detail per module), `Finora_Team_Build_Plan.docx` (track/phase/contract structure), `PROJECT.md` (live status), `SYNC_LOG.md` (session history).

---

## Universal Pre-Flight (prepend to every single prompt below)

```
Before doing anything else:
1. Read PROJECT.md in full — note the current status of the module you're about to
   work on, and of any module it depends on.
2. Read SYNC_LOG.md in full — especially any entry where "Affects other track?" is
   Yes, or "Contract impact?" is not none. Surface anything relevant to what I'm
   about to build before we start.
3. If PROJECT.md or SYNC_LOG.md contradict what I'm about to ask you to build,
   stop and flag it to me before writing any code.
Confirm you've read both files and summarize the current state back to me in
3-5 bullets before we proceed to Step 0.
```

## Universal Post-Flight (append to every single prompt below)

```
Before ending this session:
1. Update PROJECT.md — set this module's status (Not started / In progress /
   Feature-complete / Polishing / Done), tick off implemented features in §5,
   move anything deferred into §6 On Hold with a reason.
2. Add a new entry at the top of the Log section in SYNC_LOG.md using the
   template — fill in "Affects other track?" and "Contract impact?" honestly,
   even if the answer is No/none.
3. If anything in §8 Open Questions in PROJECT.md got resolved this session,
   check it off and note the decision inline.
```
